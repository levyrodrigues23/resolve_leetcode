# resolve_leetcode 🧩

Repositório com minhas soluções para problemas do [LeetCode](https://leetcode.com/). Não sou expert — o objetivo é praticar lógica, algoritmos e estruturas de dados.

---

## 📁 Estrutura do repositório

Cada problema fica em seu próprio diretório, com a convenção:

```
{número}-{nome-do-problema}/
├── README.md          # Enunciado do problema (extraído do LeetCode)
└── {nome-do-problema}.{extensão}  # Solução
```

Exemplo:

```
1-two-sum/
├── README.md
├── two-sum.py
└── two-sum.dart
```

### Linguagens utilizadas

| Linguagem  | Extensão |
|------------|----------|
| Python     | `.py`    |
| Dart       | `.dart`  |
| JavaScript | `.js`    |

## ▶️ Como executar as soluções localmente

### Python

Requer [Python 3](https://www.python.org/downloads/).

```bash
python 1-two-sum/two-sum.py
```

### Dart

Requer o [SDK do Dart](https://dart.dev/get-dart).

```bash
dart 1-two-sum/two-sum.dart
```

### JavaScript

Requer [Node.js](https://nodejs.org/).

```bash
node 2820-return-length-of-arguments-passed/return-length-of-arguments-passed.js
```

## ➕ Como adicionar uma nova solução

1. Crie um diretório seguindo a convenção `{número}-{nome-do-problema}/`.
2. Adicione o enunciado do problema em `README.md` (você pode copiar do LeetCode).
3. Crie o arquivo de solução com o nome `{nome-do-problema}.{extensão}`.
4. Atualize a tabela de problemas neste README.
